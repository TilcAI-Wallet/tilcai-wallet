# Adaptador TilcAI

Este paquete describe la frontera para cuentas, relayer y monitor de TilcAI. La base solo resuelve la passphrase de la red Stellar seleccionada. La integración requiere elegir versiones upstream, validar interfaces y probar la recuperación y conciliación. Evitar que un paquete público del workspace dependa de un registro privado para arrancar.
