# Contratos de API

`wallet-v1.ts` contiene los esquemas y rutas oficiales de la PR #10. Los importes
son cadenas de unidades atómicas; `formatUsdcMinor` es una utilidad interna para
presentar USDC con siete decimales. Los fixtures se etiquetan con `mode: fixture` y
no son evidencia de Testnet. Véase [contrato de la demo](../../docs/demo-api.md).
